# Heart Disease Prediction

A machine learning project that predicts the probability of heart disease using patient data.

**[Try the live app](https://k2g6mvu2cfeqovxqduawgj.streamlit.app/)**

## Project contents

- `heart.ipynb` — Data analysis, preprocessing, model training, and evaluation. The notebook also contains exploratory code that is not required to run the web application.
- `heart_disease_ucl.csv` — Dataset used for model development.
- `app.py` — Streamlit web application.
- `heart_disease_model.joblib` — Trained machine learning pipeline.
- `requirements.txt` — Python dependencies required to run the application.

## Run locally

1. Clone this repository.

2. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Open a terminal in the project folder and start the application:

   ```bash
   streamlit run app.py
   ```

## Disclaimer

This project is for educational purposes only. It is not intended for medical diagnosis or clinical decision-making. Do not enter real personal data.
