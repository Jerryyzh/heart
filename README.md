# Heart Disease Prediction

A machine learning project that predicts the probability of heart disease using patient data.

## Project contents

- `heart.ipynb` : data analysis, preprocessing, model training, and evaluation. This notebook contains also code all of which is not needed for this app.
- `heart_disease_ucl.csv` : dataset
- `app.py` :Streamlit web application
- `heart_disease_model.joblib` : trained model pipeline

## Run locally

1. Clone this repository.
2. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Start the application: Open terminal in the folder and run command

   ```bash
   streamlit run app.py
   ```

## Disclaimer

This project is for educational purposes only. It is not intended for medical diagnosis or clinical decision-making. Do not enter real personal data.
